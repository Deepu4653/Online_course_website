# Online Course Website

A simple landing page for a fictional online learning website, built with HTML and CSS.

## Sections
- Website header with an action link
- Navigation bar
- Welcome area with two side-by-side parts
- Course cards
- Benefits section
- Contact details

## Flexbox practice
- `justify-content: space-between` and `align-items: center` in the header
- `justify-content: space-around` in the welcome area
- `align-items: flex-start` for course cards
- `justify-content: space-evenly` for benefits
- Column layouts on small screens

## Files
- `index.html` - webpage content
- `style.css` - webpage design

## Run
Open `index.html` in a web browser.

## GitHub Pages
Upload `index.html` and `style.css` to a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
